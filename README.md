# HC Encyclopedia

Open-source помощник для игроков Hustle Castle.

## Возможности

- синхронизация базы SageHC (предметы, сеты, руны)
- локальная база SQLite
- веб-интерфейс на русском: поиск, фильтры, карточки
- несколько игровых профилей (в разработке)
- оптимизация рун (в разработке)
- оптимизация экипировки (в разработке)
- анализ состава команды (в разработке)

## Установка

```bash
pip install -e .
```

## Первичный запуск

```bash
hcenc db init                # создать базу database/game.sqlite
hcenc sync items             # список предметов
hcenc sync item-details      # карточки предметов (описания, уровни, слоты)
hcenc sync sets              # список сетов
hcenc sync set-details       # бонусы, субстанции, материалы
hcenc sync set-images        # картинки сетов
hcenc sync runes             # список рун
hcenc sync rune-details      # описания рун по классам
hcenc sync rune-images       # картинки рун
```

Команды синхронизации идемпотентны: повторный запуск докачивает только
недостающее (HTML-карточки кэшируются в `assets/cache/`).

## Веб-интерфейс

```bash
hcenc serve
```

Откройте http://127.0.0.1:8000 — энциклопедия с поиском и фильтрами:

- **Предметы** — поиск по названию/коду, фильтры по классу и слоту
- **Сеты** — карточки с бонусами 2/4/6, субстанциями и материалами
- **Руны** — тип, событие, коллекция, описания для танка/мага/лучника
- **Отряд** — ваши юниты и подбор экипировки

## Инвентарь и подбор экипировки

1. В каталоге **Предметы** отмечайте галочкой ✅ то, что у вас есть;
   фильтр «только мои» показывает инвентарь.
2. На странице **Отряд** создайте юнита: имя, класс (танк/маг/лучник), уровень.
3. В карточке юнита выберите **сет** — его бонусы 2/4/6 отображаются
   тут же; сет также виден в списке отряда.
4. Для каждого слота (оружие, броня, кольцо, амулет, артефакт, тотем)
   выбирайте предмет из отмеченных «в наличии».
   Оружие фильтруется по классу юнита.

Примечание: SageHC не отдаёт состав сетов (какие предметы входят
в сет), поэтому предметы сета надеваются вручную.

Данные инвентаря и отряда хранятся в локальной базе и не зависят
от синхронизации с SageHC.

Интерфейс и игровые термины — на русском. Названия и описания SageHC
отдаёт только на английском; поля `name_ru`/`description_ru` в базе
зарезервированы под русский перевод.

Другие параметры запуска сервера:

```bash
hcenc serve --host 0.0.0.0 --port 8080
```
